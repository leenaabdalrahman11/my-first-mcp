# Demo Script

## 0:00–0:40 — Problem

Explain the problem:
Job applications are difficult to track manually. The MCP server helps users manage, search, and update their job applications through natural language.

## 0:40–1:10 — Architecture

Explain the architecture:
- User interacts with an AI model.
- The model communicates with the Job Application Tracker MCP server.
- The MCP server provides tools for managing job applications.
