# Final Reflection

## Wins

During this six-week journey, I built my first Model Context Protocol (MCP) project: **CareerPilot MCP**, a job application tracker server built with TypeScript using the official MCP SDK.

The main achievements of this project include:

- Built a functional MCP server that helps users manage job applications.
- Created three MCP tools:
  - `add_job` to add new job applications.
  - `list_jobs` to display saved applications.
  - `update_job_status` to update application statuses.
- Implemented local data storage using a JSON file.
- Used TypeScript to build a structured and maintainable codebase.
- Added input validation to ensure reliable tool usage.
- Tested MCP tools using MCP Inspector.
- Created documentation and example conversations to make the project easier to understand and use.
- Published the project as a public GitHub repository.

This project helped me understand how AI applications can interact with external tools through the Model Context Protocol.

---

## Blockers

The most challenging parts of this project were:

- Understanding the MCP architecture and how MCP servers communicate with AI clients.
- Learning how to structure tools correctly using the MCP SDK.
- Debugging tool execution and testing different inputs and responses.
- Designing a simple but reliable data storage solution using JSON.
- Handling validation and ensuring users provide the required information.

Working through these challenges improved my debugging skills and helped me gain more confidence in building AI-powered applications.
